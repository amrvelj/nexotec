## Country reference list — `app/platform/reference_data_seed/countries.csv` (KAN-32)

The seed rows for the `country` reference list were generated by
`scripts/gen_country_reference_seed.py` from two sources:

### Unicode CLDR — country names (de / fr / it / en)

The localized country names are taken from the Unicode Common Locale Data
Repository (CLDR), accessed through the [Babel](https://babel.pocoo.org/)
library (`Locale(...).territories`).

- Source: <https://cldr.unicode.org/>
- Licence: Unicode License v3 (Unicode-3.0), <https://www.unicode.org/license.txt>

CLDR is the source of record for the `label_de` / `label_fr` / `label_it` /
`label_en` columns in `countries.csv`.

### Google Dataset Publishing Language — `countries.csv` (code-set cross-check)

Google's canonical `countries.csv` from the Dataset Publishing Language sample
data was used **only as a cross-check on the set of ISO 3166-1 alpha-2 codes**
(which codes exist). No column of Google's file is redistributed: the checked-in
CSV's labels all come from CLDR, and its code set is the reconciliation of
Google's list with CLDR's territory set (see the script and the KAN-32 PR for
the specific additions and removals).
